## Project

Jarvis is a personal assistant project (inspired by Iron Man's Jarvis / Batman's Alfred). The project is in its early stages — no tech stack has been committed to yet.

## Getting Started

This repository is currently empty of source code. Before development can begin, the following decisions need to be made:

- **Language / runtime** (e.g., Python, Node.js)
- **Core capabilities** (voice, text, automation, API integrations, etc.)
- **Architecture** (monolith, microservices, plugin system, etc.)

Once those are settled, update this file with build, test, and lint commands, along with the architectural overview.
